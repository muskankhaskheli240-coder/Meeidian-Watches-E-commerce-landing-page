# Meridian — Watches E-commerce Landing Page

A responsive, front-end e-commerce landing page for **Meridian**, a fictional independent watchmaking brand. The project showcases a full product-marketing landing page — hero section, collections, product listing, brand story, testimonials, FAQ, and contact — built with modern HTML, CSS, and JavaScript.

🔗 **Live Demo:** [https://muskankhaskheli240-coder.github.io/Meeidian-Watches-E-commerce-landing-page/](https://muskankhaskheli240-coder.github.io/Meeidian-Watches-E-commerce-landing-page/)

---

## 📌 Overview

Meridian is designed as a premium watch brand landing page, highlighting:
- In-house craftsmanship and product storytelling
- A browsable, filterable watch collection
- Trust-building sections (warranty, shipping, returns, materials)
- Brand history and company timeline
- Customer testimonials and FAQs
- A working newsletter/contact form layout

---

## ✨ Features

- **Responsive Design** — Adapts across desktop, tablet, and mobile screens
- **Dark / Light Mode Toggle** — Theme switcher for user preference
- **Product Filtering & Sorting** — Filter by category (Diver, Pilot, Chronograph, GMT, Minimalist, Dress) and sort by price, rating, or popularity
- **Search Functionality** — Quick search bar for finding watches by name/keyword
- **Shopping Bag & Wishlist UI** — Cart and favorites panel with subtotal, shipping, and tax breakdown
- **Countdown Timer** — Live countdown for limited-time sale offers
- **Expandable Content Sections** — "Read more" accordions for feature details
- **Brand Story Timeline** — Company milestones from 1926 to present
- **Testimonials Carousel** — Customer reviews section
- **FAQ Section** — Common questions about shipping, warranty, and servicing
- **Contact Form** — Inquiry form with subject categorization and store info (location, hours, phone, email)
- **SEO & Social Meta Tags** — Open Graph and Twitter Card metadata for link previews
- **Accessibility Considerations** — Skip-to-content link, semantic sections, labeled inputs

---

## 🛠️ Tech Stack

- **HTML5** — Semantic page structure
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Interactivity (filtering, search, theme toggle, cart/wishlist, countdown timer)
- **GitHub Pages** — Deployment/hosting

## 🚀 Getting Started

### Prerequisites
No build tools required — this is a static front-end project.

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/muskankhaskheli240-coder/Meeidian-Watches-E-commerce-landing-page.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd Meeidian-Watches-E-commerce-landing-page
   ```

3. **Open in browser**
   Simply open `index.html` in your browser, or use a live server extension (e.g., VS Code Live Server) for auto-reload during development.

## 🌐 Deployment

This project is deployed using **GitHub Pages** directly from the repository.

To deploy your own version:
1. Push your code to a GitHub repository
2. Go to **Settings → Pages**
3. Select the branch (usually `main`) and root folder
4. Save — your site will be live at `https://<username>.github.io/<repo-name>/`
